# User Roles

## Purpose
This document defines the Role-Based Access Control (RBAC) model.

## Content
### Roles Summary

| Role | Primary Interface | Permissions |
|---|---|---|
| **Citizen** | Mobile PWA (No auth required). | Submit reports, view status, view public risk heatmaps. |
| **Field Worker** | Mobile task app. | View assigned tasks, update completion status. |
| **Municipal Officer** | Decision Dashboard. | View queues, override recommendations, review AI justifications. |
| **Administrator** | City Panel. | Sliders, simulator variables, system configs. |
