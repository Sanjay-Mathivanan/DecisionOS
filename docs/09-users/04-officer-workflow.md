# Municipal Officer Workflow

## Purpose
This document defines the operational duties of the Municipal Officer.

## Content
### Officer Actions
- **Review Priority Queue**: Review incidents sorted by priority.
- **Analyze Explanations**: Click on an incident to view SHAP metrics and cost breakdowns.
- **Act on Resource Allocations**: Approve the system's recommended dispatch or override it (e.g., redirect Team A to Team B's location) and submit a reason text.

```
[View Queue] ──► [Review Justification] ──► [Approve / Override with Reason]
```
