# Data Sources

## Purpose
This document details the specific public and synthetic data sources.

## Content
### Target Public Datasets
- **India Open Government Data Platform (data.gov.in)**: Ingestion of rainfall patterns, demographic census data, and general municipal metrics.
- **Geospatial Basemaps**: OpenStreetMap (OSM) for road networks and landmark coordinates.

### Synthetic Data Composition
Synthetic generators model:
- 100 random coordinates in a target city zone.
- Resource sheets: 20 workers, 5 vehicles, 3 departments, and a ₹10 lakh budget.
- *Rule: Synthetic data must be explicitly labeled as such in academic papers.*
