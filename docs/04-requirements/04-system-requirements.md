# System Requirements

## Purpose
This document outlines hardware and software requirements.

## Content
### Software Prerequisites
- **Operating System**: Linux (production) / Windows (development).
- **Database**: PostgreSQL (v14+) with PostGIS extension.
- **Programming Languages**: Python (v3.9+), TypeScript (v4.5+).
- **Frameworks**: FastAPI, React.
- **Libraries**: PyTorch, scikit-learn, XGBoost, Google OR-Tools, Leaflet/MapLibre.

### Hardware Prerequisites (AI Server)
- **CPU**: 8-core modern processor.
- **RAM**: 16 GB minimum.
- **GPU**: NVIDIA GPU with Cuda support (8 GB VRAM recommended for vision inference).
