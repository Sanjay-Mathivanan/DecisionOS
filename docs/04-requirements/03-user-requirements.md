# User Requirements

## Purpose
This document presents user needs and usability requirements.

## Content
### User Profiles
1. **Citizens**: Require a simple, lightweight Web/PWA interface (no login required to submit issues).
2. **Municipal Officers**: Require a priority queue interface displaying urgent alerts, map interfaces, and simple Approve/Override buttons.
3. **Administrators**: Require high-level dashboards, hotspot analytics, budget trackers, and simulation sliders.

### Usability Goals
- Citizen report submission must require fewer than 3 taps.
- Officer dashboard must load priority tasks in under 1 second.
- Explanations must be displayed in plain language (e.g., "Merged because complaints are within 120m").
