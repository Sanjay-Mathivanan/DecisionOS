# Project Risks

## Purpose
This document outlines potential obstacles and risk-mitigation strategies.

## Content
### Risk Analysis

| Risk | Impact | Mitigation Strategy |
|---|---|---|
| **Scope Creep** | High | Strictly adhere to the MVP boundaries defined in the documentation. |
| **Data Scarcity** | Medium | Utilize synthetic datasets for resource optimization and simulation testing. |
| **GPU Access Limitations** | Medium | Use lightweight model variants (DistilBERT, YOLOv8 nano). |
| **API Integration Issues** | Low | Run under Mode A (Academic Mode) with static CSV files. |
