# Data Security

## Purpose
This document details records security and encryption standards.

## Content
### Protocols
- **Transport Security**: TLS 1.3 enforced for all browser sessions.
- **PII Obfuscation**: Sensitive reporter fields are hashed inside PostgreSQL database columns.
