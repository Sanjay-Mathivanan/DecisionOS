# Evaluation Metrics

## Purpose
This document defines the quantitative metrics used to evaluate DecisionOS Civic.

## Content
### Four Evaluation Categories

#### 1. AI Evaluation
- **Classification**: Accuracy, Precision, Recall, F1-score.
- **Detection (CV)**: mean Average Precision (mAP), Intersection over Union (IoU).
- **Forecasting**: Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), Mean Absolute Percentage Error (MAPE).
- **Clustering**: Silhouette score.

#### 2. Optimization Evaluation
- Operational Cost reductions.
- Dispatch response time reductions.
- Expected impact reduction.

#### 3. Explainability Evaluation
- Explanation consistency.
- Feature importance variance.
- Subjective admin trust surveys.

#### 4. System Evaluation
- API latency, network throughput, and database query response times.
